# ⚡ VFXEdu CorridorKey 2.0 - DaVinci Resolve Integration Guide

**Blackmagic Design DaVinci Resolve(다빈치 리졸브)**의 **Edit(에디트)** 및 **Color(컬러)** 페이지에서 그린/블루스크린 영상을 원클릭으로 키잉하는 전용 파이프라인 연동 도구입니다.

---

## 🌟 주요 특징 (Key Features)

1. **타임라인 원클릭 키잉 (Edit / Color 페이지)**:
   - 플레이헤드를 원하는 영상 클립 위에 올려두고 메뉴 클릭 한 번으로 해당 클립을 자동 감지하여 AI 키잉을 실행합니다.
2. **ProRes 4444 알파 채널 네이티브 지원**:
   - 다빈치 리졸브의 업계 표준인 **Apple ProRes 4444 (10-bit RGBA)** 포맷으로 렌더링되어 별도 설정 없이 완벽한 투명도(Alpha)를 인식합니다.
3. **타임라인 V2 트랙 자동 배치 (Auto Overlay)**:
   - 렌더 완료 시 미디어 풀(`CorridorKey_Matte` 빈)에 자동 등록되고, 타임라인의 원본 클립 바로 윗 트랙(V2)에 동일한 위치/길이로 자동 배치됩니다.
4. **컬러 페이지 외부 매트(External Matte) 연동**:
   - 미디어 풀에 임포트된 매트를 컬러 페이지 노드에서 마우스 우클릭 → `Add Matte`로 즉시 연결하여 인물만 분리 보정 가능합니다.
5. **독립형 포터블 엔진 구동**:
   - 다빈치 리졸브와 완전히 격리된 무설치 포터블 Python(PyTorch + CUDA 12.8) 환경을 백그라운드로 호출하므로 리졸브가 멈추거나 충돌하지 않습니다.

---

## 📥 설치 방법 (1초 원클릭)

1. CorridorKey 2.0 포터블 폴더에서 **`Install_To_Resolve.bat`**를 더블 클릭합니다.
2. 스크립트가 다빈치 리졸브의 스크립트 폴더에 자동 등록됩니다:
   - `Edit`, `Color`, `Utility` 메뉴에 동시 탑재

---

## 🚀 사용 방법 (Quick Start)

1. **다빈치 리졸브 실행**:
   - **Edit 페이지** 또는 **Color 페이지**로 이동합니다.
2. **클립 선택**:
   - 타임라인의 그린/블루스크린 클립 위에 타임라인 **플레이헤드(빨간색 인디케이터)**를 위치시킵니다.
3. **스크립트 실행**:
   - 상단 메뉴: **`Workspace` → `Scripts` → `CorridorKeyer`** 클릭.
4. **파라미터 조절 및 렌더링**:
   - 나타난 대화상자에서 클립 정보(파일명, 인/아웃 범위)를 확인합니다.
   - 포맷 선택 (기본: `ProRes 4444 MOV with Alpha`).
   - 디스필(반사광 제거) 강도 조절.
   - **`[ 🚀 Key Selected Clip ]`** 버튼 클릭!
5. **완료 및 확인**:
   - 작업이 끝나면 타임라인 트랙 V2에 키잉된 투명 영상이 자동 배치됩니다.
